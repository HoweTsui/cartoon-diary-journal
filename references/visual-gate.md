# 视觉门禁：人物结构与日记页

这是每次调用生图前和出图后都必须执行的 P0 检查。它解决“文字规则写了，但模型仍回退为普通可爱人物”的问题。

## 参考优先级

1. 本文件和 `style-system.md`：**人物/动物结构的唯一硬标准**。
2. 本次任务 `character-lineup.png`：只锁定该任务角色的头型、发型、服装、配饰、耳尾和相对比例。
3. `assets/style-reference/diary-style-anchor.png`：只锁定 9:16 横线纸、顶部日期标题、纵向叙事、留白和线条密度；**不得继承其中示例人物的脸朝向、头身比、手脚或宠物结构**。
4. 用户照片：只提取身份线索；绝不能覆盖前三项。

不要把仓库里的公开示例人物、旧海报或其他任务图集当作当前角色的身份参考。

## 图集先验收，失败先重绘

日记页不能拿不合格图集“将就生成”。先打开本次 `character-lineup.png`：只要任一角色近正面、鼻子变成普通 C 形/闭合圈、短弧到鼻根的空白断口消失、肢体变粗、动物拟人直立或写实化，就先重绘整张图集，再生成日记页。

人物鼻子的前端必须是朝向一侧的、略扁且上方断开的线描半椭圆；不能变成贴在脸边的普通 C 形或嘴形。人物头型是略圆的有机侧向头，不是正面圆脸，也不是硬折角轮廓。动物保持物种姿态：猫狗默认四足或自然坐伏，不能变成人形直立角色。

## 调用生图前：附图顺序

1. 本次任务的实际 `character-lineup.png`，标注为“身份参考”。
2. `diary-style-anchor.png`，标注为“仅版式参考”。
3. 用户照片（若有），标注为“仅身份线索”。

先在文字提示首段写出下列五条，不能只放在长提示词尾部：

1. 人物为约 25°–35° 的偏正半侧面，完整显示两只同尺寸、无高光的正圆黑豆豆眼；眼睛略高，外侧眼不贴轮廓并保留白边；头宽接近头高，不能拉成长侧脸。动物保持物种正确的半侧面。
2. 人脸前外侧先保留一小段贴着头形、从发际/刘海末端弧向眉线位置（不画眉）的短弧形轮廓线；该短弧末端到鼻根保留约 1.5 个眼点高度的清晰空白断口。断口中无眉线、额头线、鼻梁线或补轮廓；不得把这段轮廓画成长直线。
3. 人鼻为不填黑、上方开口的略扁半椭圆；动物鼻为单一实心黑鼻，猫鼻更小且位于双眼下方中央。
4. 人与动物均为窄身板和极细双线肢体；手掌/爪掌可略大，整条手臂、腿或动物肢体不得加粗。
5. 人物图集和日记页必须复用同一头型、双眼间距、鼻向、发型/耳尾、服装黑块、肢体和鞋/爪掌结构。

## 出图后：逐角色二值验收

用 `view_image` 逐场查看。以下任何一项为“否”，整页失败并重生成，不以“接近”交付：

- 是否为半侧面，且同时清楚看到两只等大的正圆黑眼和侧后耳？
- 人脸短弧末端到鼻根是否有清晰空白断口；人物鼻是否只有一个、上方开口且不填黑？
- 人物手臂、大腿、小腿是否均为可见白缝的极细双线管；躯干是否明显窄于头？
- 是否每个全身/坐姿人物都有裤腰、裆部、清晰裤脚下沿、两条独立裤腿，且裤脚与小腿之间有白色分割？
- 动物是否有大头、窄躯干、细肢、略大爪掌、完整双耳双眼口鼻尾巴；且没有写实毛发、高光或解剖细节？
- 是否与本次人物图集逐项一致，而非变成普通可爱人物、正面证件照、半写实人物或写实宠物？
- 图集自身是否已通过以上相同检查？若否，是否已先重绘图集而非继续用它生成日记？

## 返工指令

失败时只针对失败点重写提示词首段，例如“第三场人物回到近正面；改为左向 30° 偏正半侧面，补全右眼、短弧后空白断口和极细双线前臂”。不要用裁切、文字解释或接受局部错误的方式掩盖问题。
