# 视觉门禁：人物结构与日记页

这是每次调用生图前和出图后都必须执行的 P0 检查。它解决“文字规则写了，但模型仍回退为普通可爱人物”的问题。

## 参考优先级

1. 本文件和 `style-system.md`：**人物/动物结构的唯一硬标准**。
2. `assets/style-reference/character-lineup-demo.png`：确认版公共几何锚点，只锁头脸、鼻型、眼位、头身比、肢体、裤脚与脚掌结构，不锁姓名、发型、衣物或身份。
3. `assets/style-reference/face-geometry-closeup.png`：放大锁定双眼、前侧短弧/空白断口、人鼻和动物鼻；不锁身份。
4. 本次任务 `character-lineup.png`：只锁定该任务角色的头型、发型、服装、配饰、耳尾和相对比例。
5. `assets/style-reference/diary-layout-only.png`：只锁定 9:16 横线纸、顶部日期标题、纵向叙事、留白和线条密度；它没有人物，**不得从版式图推断角色结构**。
6. 用户照片：只提取身份线索；绝不能覆盖前五项。

不要把仓库里的公开示例人物、旧海报或其他任务图集当作当前角色的身份参考。

## 图集先验收，失败先重绘

日记页不能拿不合格图集“将就生成”。先打开本次 `character-lineup.png`：只要任一角色近正面、鼻子变成普通 C 形/闭合圈、短弧到鼻根的空白断口消失、肢体变粗、动物拟人直立或写实化，就先重绘整张图集，再生成日记页。

人物鼻子的前端必须是朝向一侧的、略扁且上方断开的线描半椭圆；不能变成贴在脸边的普通 C 形或嘴形。人物头型是略圆的有机侧向头，不是正面圆脸，也不是硬折角轮廓。动物保持物种姿态：猫狗默认四足或自然坐伏，不能变成人形直立角色；猫脸零胡须线，不能以胡须补充表情。

## 调用生图前：附图顺序

1. 本次任务的实际 `character-lineup.png`，标注为“身份参考”。
2. `assets/style-reference/character-lineup-demo.png`，标注为“确认版公共结构参考”。
3. `assets/style-reference/face-geometry-closeup.png`，标注为“放大五官结构参考”。
4. `diary-layout-only.png`，标注为“仅版式参考、无人物”。
5. 用户照片（若有），标注为“仅身份线索”。

在调用前，为每个场景单独列出“角色 ID → 图集 `col`/`row` → 全部 `anchors`”的角色卡。主角的图集格位和锚点不能作为配角、路人或宠物的默认结构；每一个可见角色都必须独立命中自己的角色卡。

先在文字提示首段写出下列五条，不能只放在长提示词尾部：

1. 人物为约 25°–35° 的偏正半侧面，完整显示两只同直径、无高光的几何正圆纯黑豆豆眼；每只眼均为无外轮廓的实心圆盘，禁止椭圆、杏仁眼、空心眼或不规则点眼。眼睛略高，外侧眼不贴轮廓并保留白边；头宽接近头高，不能拉成长侧脸。动物保持物种正确的半侧面。
2. 中性人脸只允许双眼、单鼻和低位嘴。前外侧先保留一小段贴着头形、从发际/刘海末端弧到外侧眼上方的短弧形轮廓线；该短弧末端到鼻根保留约 1.5 个眼点高度的清晰空白断口。断口中不能有任何线或额外五官标记；不得把这段轮廓画成长直线。
3. 人鼻为不填黑、上方开口的略扁半椭圆；动物鼻为单一实心黑鼻，猫鼻更小且位于双眼下方中央。
4. 人与动物均为窄身板和极细双线肢体；每根肢体管径不超过头宽约 1/18，内部必须保留白缝；手掌/爪掌可略大，整条手臂、腿或动物肢体不得加粗。
5. 人物图集和日记页必须复用同一头型、双眼间距、鼻向、发型/耳尾、服装黑块、肢体和鞋/爪掌结构。
6. 人鼻必须横向宽于高、朝面向侧伸出，不能画成向下 U/C 形；站立人物头高至少约占全身高度 30%，短裤下小腿不得长于约一个头高。

## 出图后：逐角色二值验收

用 `view_image` 逐场查看。以下任何一项为“否”，整页失败并重生成，不以“接近”交付：

- 是否为半侧面，且同时清楚看到两只同直径、无轮廓、实心几何正圆黑眼和侧后耳？
- 人脸短弧末端到鼻根是否有清晰空白断口；人物鼻是否只有一个、上方开口且不填黑？
- 人鼻是否横向朝面向侧，而不是向下 U/C 形？站立人物的头是否明显大、身体是否没有被拉成长比例？
- 人物手臂、大腿、小腿是否均为可见白缝的极细双线管；躯干是否明显窄于头？
- 是否每个全身/坐姿人物都有裤腰、裆部、清晰裤脚下沿、两条独立裤腿，且裤脚与小腿之间有白色分割？
- 动物是否有大头、窄躯干、细肢、略大爪掌、完整双耳双眼口鼻尾巴；且没有写实毛发、高光或解剖细节？
- 是否与本次人物图集逐项一致，而非变成普通可爱人物、正面证件照、半写实人物或写实宠物？
- 每个可见角色是否均能对应到当前场景的角色卡和自己的图集格位，而不是把主角结构套给配角或宠物？
- 图集自身是否已通过以上相同检查？若否，是否已先重绘图集而非继续用它生成日记？

## 返工指令

失败时只针对失败点重写提示词首段，例如“第三场人物回到近正面；改为左向 30° 偏正半侧面，补全右眼、短弧后空白断口和极细双线前臂”。不要用裁切、文字解释或接受局部错误的方式掩盖问题。
