# 生图视觉门禁

这是调用 ImageGen 前后都要执行的 P0 清单。参考图只抽取结构语义，不复制出版物或私人原图。

## 当前 0.2.4 肢体与比例覆盖规则

首轮人物与动物肢体杆部统一按头宽约 `1/32` 的超细目标生成；旧版 `1/28` 仅作兼容上限，`1/24` 仍是绝对失败上限。头部、手掌/爪掌和鞋/脚保持确认版尺寸，躯干、肩髋间距及头部以下身体段按上一版角色卡约 90% 处理，即身体比例缩短约 10%。视角只允许 25°–35° 偏正半侧面，禁止正面、真正 90° 正侧面和单眼全侧面；该段规则优先于下方旧版示例措辞。

## 调用前

1. 已读取实际任务图谱、角色独立 1:1 头像（如有）、公共几何图集、脸部几何特写和无人物版式图；四张固定输入图按固定顺序提供，版式图不得提供人物结构；事件 `sourceImages` 追加在固定参考之后。
2. 已完成每张固定参考和每张 `sourceImages` 的内部 scene inventory：主体/动物、数量、动作和表情、前中后景关系、必须保留文字/形状、可简化细节。
3. 已将每场拆成 `must_keep` 与 `flexible` 两层；硬事实包含主体、关键道具/数量、核心动作和关系，灵活层只包含次要道具、背景及相对区域内的精确摆位。
4. 已为本页所有可见角色逐一绑定角色 ID、头像/图集格位和外观锚点；没有身份数据时只保留用户可见事实，不猜身份。
5. 已为每场根据事件选择表情原子和强度：`neutral_dot`、`closed_arc`、`half_lid`、`wide_round`、`crossed` 仅限这些参考派生原子。

## P0 结构门禁

### 头脸最高优先级

先按确认版头脸模板验收，再看场景和表情：近圆且不拉长的头、两枚同直径正圆眼（外侧眼留白）、眼下短横向开放人鼻、鼻下低位分离嘴，以及短弧后的空白断口。若头型、眼位、鼻长或嘴鼻关系漂移，整页重生，不用场景道具或发型解释。

- 画幅为新默认 3:4，纯白纸和 14–18 条浅青横线；人物、动物、道具、可见配饰（包括眼镜框、镜桥和镜腿）和背景环境为同一档约 5–6px 黑线。
- 人物/动物明确左或右 25°–35° 偏正半侧面，鼻尖/口鼻横向伸出，头脸与躯干同向；禁止正面、标准 90° 正侧面（直侧脸）、单眼全侧面、居中鼻子、对称肩耳或正面头接侧身。耳朵只保留外轮廓，内部留白，不画内耳修饰线。
- 人头接近正圆但保留角色差异；前外侧短弧结束后到鼻根有约 1.5 个眼点高度的清晰空白断口。断口内不能出现眉线、额头线、鼻梁线或其他标记。
- 人物中性眼是两枚等大的正圆黑点，外侧眼离轮廓留白；表情眼只能换成列出的受控原子，不能出现任意椭圆、杏仁、心形、钱币、高光或不规则形。
- 人物必须有一个单独、清晰可见、上方开口、不填黑的线描半椭圆鼻，不能省略、隐藏、并入轮廓或被嘴替代；不能是下垂 U/C、实心黑鼻、鼻孔或闭合 O；动物只有一个物种正确且清晰可见的实心黑鼻，不能套用人物鼻。
- 人物上臂、前臂、大腿、小腿和动物不含爪掌的肢体杆部共用同一超细目标：首轮目标约头宽 1/32，旧版 1/28 仅作兼容上限；外轮廓绝不超过头宽约 1/24、彼此误差不超过 10%；手臂和腿杆必须一样细，手掌/爪掌只在末端略大。头部、手掌和鞋/脚保持确认版尺寸，躯干与头部以下身体段按上一版卡片约 90% 处理，身体比例缩短约 10%。
- 短裤/长裤有裤腰、裆部分隔、两条裤腿和裤脚下沿；裤脚与细小腿之间有白色分割，不能把布料宽度延续到小腿。
- 每页一张海报、默认四个主叙事区；单事件是大主场景加 1–3 个真实相关细节，多事件全部聚合进四区，不做漫画分格、不删除 `must_keep`。
- 日期和标题上方/下方关系正确且居中，字号固定；每场 4–10 字备注固定放在右侧栏，场景间至少一条横线高度空白。

## 表情检查

表情先通过嘴形、露齿、身体反应、手势和最多两个外置符号表达，再使用眼睛原子。`wide_round` 仍须是成对圆形；`closed_arc`/`half_lid`/`crossed` 只能在事件语义支持时出现。表情不得改变头型、鼻子、断口、眼位、发型、肢体长度或物种结构。宠物互动只是事件修饰，不单独生成重复角色或特殊眼形。

## 出图后逐项对照

按来源清单逐项比对主体数量、动作、道具、相对关系、备注文字和眼/嘴表情；再比对每名角色的头型、眼原子、清晰鼻子、断口、耳内空白、发型/耳尾、衣物、配饰线宽、头身比、四肢管径和脚掌。凡 `must_keep` 丢失、身份/几何漂移、文字乱码、人物或可见配饰线宽不一致、正面化、鼻子丢失、耳内修饰线、粗肢体或宠物人化，均整页重生。

非关键道具或摆位偏差最多自动修正两轮；超过两轮或仍无法判断时，亲切地只问一个会改变故事含义的具体问题，不交付明显失败图。
