# 人物图库与关系

## 数据地位

`assets/character-library/character-graph.html` 与 `character-lineup.png` 只提供结构和画风参考。仓库内任何人物名称、头像和关系都可能属于某次本地任务，不能作为公开包或新任务的默认人物库；每次实际任务都必须整体替换为本次数据。

每个实际任务必须生成一份任务专用图谱和人物图集。图谱只表达全局身份与关系，不写日期、周几、当日事件或时间线。

## 生图前匹配

按以下顺序检查日记里的每个角色：

1. 在任务 HTML 的 `graph-data.nodes` 中匹配角色 ID 或准确姓名。
2. 未精确命中时，再用身份说明、外观锚点和人物备注做唯一匹配。
3. 唯一命中时，读取该节点的 `col`、`row` 和 `anchors`，从任务人物图集中使用对应格位。
4. 无命中或多重命中时停止生图，列出角色并要求用户提供清晰图片。不得猜测或套用模板人物。
5. 收到图片后先按现有图集风格转绘，再把新角色写入任务图集和图谱，重新构建 HTML 并再次执行匹配，全部通过后才继续日记生成。

## 实际数据结构

以 `assets/templates/character-graph-data.example.json` 为结构模板。每个节点必须包含：

- 唯一 `id` 与本次任务的实际 `name`。
- 实际 `role`。
- 与任务人物图集一致的 `col`、`row`。
- 可选 `avatarFocusX`、`avatarFocusY`（0–1）：头像裁剪焦点；人物默认约为 `0.5, 0.36`，动物可把 `avatarFocusY` 调低或调高以完整容纳全身。
- 图谱初始位置 `x`、`y`。
- 至少四条可观察 `anchors`，并必须覆盖：25°-35° 偏正半侧面朝向与双正圆豆豆眼（外侧眼留白）、脸型及前外侧短弧后到鼻根的空白断口、人类开放线描鼻或动物实心黑鼻、低位嘴、发型/耳尾或配饰、窄身板与极细四肢、服装/黑块及鞋或爪掌。长鼻方向仅在该人物本身具有长鼻时记录。
- 可选的长期 `notes`；不得放某一天的日志事件。

每条关系必须包含实际 `source`、`target`、`label`、`type` 和 `curve`。关系端点必须存在于同一份节点数据中，两个人物之间只保留一条边。

## 整体替换占位数据

不要在模板数组后追加人物或关系。运行：

```bash
python3 scripts/build_character_graph.py <actual-character-data.json> \
  --output <task-output>/character-graph.html
```

脚本整体替换 HTML 的 `graph-data`，输出标记为 `status: actual`，并校验所有关系端点、图集格位和头像裁切信息。把实际人物图集按 `atlas.src` 指定的文件名放在输出 HTML 同目录。数据变化后缓存键自动变化，不会加载上一个任务的本地人物。

交付前检查：

1. `graph-data` 与实际 JSON 的人物数、人物字段、关系数和关系字段完全一致。
2. HTML 中没有任何未属于本次任务的旧占位姓名、身份、锚点、备注或关系描述。
3. 人物图集的格位数、人物顺序与 `col`、`row` 完全一致。
4. 图谱页面没有日期、周几或日记时间线。

## 图集更新

对缺失角色使用用户图片时，只把原图作为当次临时身份输入。先提取发型轮廓、服装/配饰块面、体态、宠物耳尾与毛色，再以当前人物图集作为唯一转绘标准：复用中粗黑线、25°-35° 偏正半侧面、双完整正圆豆豆眼（外侧眼留白）、前外侧短弧后到鼻根的空白断口、人兽分离的单鼻语法、低位嘴、窄身板、极细双线管状四肢、偏大扁鞋/略大爪掌和统一头身比。人物使用上方断开的线描半椭圆鼻且绝不填黑；动物使用物种正确的单一实心黑鼻且绝不使用人物鼻。不得把照片的皮肤、毛发、材质、光影、正面角度、真实比例或背景带入结果，也不得强制所有角色使用长鼻。生成后对照图集检查视角、线重、五官位置、断口、人兽鼻型、四肢结构和黑白块面；任一项漂移就重生成。不得嵌入或复制原图。图集保持规则等分网格；超过现有容量时调整 `atlas.cols`、`atlas.rows`，同时重新生成整张任务图集，避免画风和裁切漂移。

## 图集与日记一致性门禁

- 日记中的每个角色必须逐场复用图集对应格位的头型、朝向、双眼间距、鼻型、嘴位、发型/耳尾、服装黑块和肢体比例；不能只保留相似发型。
- 图集中的人物与动物也必须使用同一套半侧面规则，禁止图集为正面而海报为半侧面，或反过来。
- 同一角色在日记任一场景出现正面、黑色人鼻、人物式动物鼻、粗身板、粗肢体或缺少脸部断口时，身份匹配判定为失败，重新生成受影响整页。

## HTML 交互

- 浏览态只显示人物和关系纯文本，不显示编辑输入框、删除按钮、新增人物或新增关系表单。
- 点击“编辑”后显示人物字段、新增人物和新增关系表单。
- 编辑态双击画布上的连线名称，使用内联输入框修改；按 Enter 保存并持久化，按 Escape 取消且不改原值。
- 编辑态从节点右侧 `+` 控制点拖到另一节点可吸附建连。
- 编辑态把已有连线端点向节点外拖出可断开关系。
- 拖动任一人物靠近其他人物时，其他节点平滑避让；碰撞范围必须包含人物姓名，最终节点和姓名均不得互相遮挡。
- 点击“编排”时，无环图使用层次布局，有环或稠密图使用力导向布局；完成后可用撤销、重做恢复任意位置快照。超过 50 个节点时必须分帧计算。
- 节点位置和编辑结果写入按人物数据隔离的 `localStorage`；要正式入库仍需重新运行构建脚本并同步任务人物图集。
