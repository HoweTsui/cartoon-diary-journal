# 视觉规范

这是提示词使用的唯一视觉文字规范；数值由 geometry.json 注入，不从图片声称测量所得。这些是原创设计目标，需在生成草稿中人工验证可行性，用户确认后固定为角色版本。

所有尺寸以该角色标准头宽 H 为单位；geometry 中 stroke 是每根黑线宽，innerGap 是两线之间净白缝，outerWidth=2*stroke+innerGap 是肢体总外宽。每项允许相对 canonical 目标最多10%误差，手臂与腿杆宽度互差也不超过10%，两线之间必须有正白缝。不要另设固定像素线宽。统一人物局部线重；同一场景的配饰、道具、背景沿用邻近人物的墨线尺度，较小动物按自己的 H 定义，不套主角像素宽度。

human、cat、dog 使用各自的 canonical 尺寸。人类已认可的手臂和小腿粗细不变。裸露肢体每段总共只有两条外轮廓线，两线之间完全纯白；禁止第三条线、内部中线、排线、筋腱线或把每条轮廓再次描边。弯曲只改变两条外轮廓的走向，不在肘膝内部补线。肢体长度沿弯曲路径计算，计算路径不绘制。衣料可宽但裤脚/袖口与肢体有清晰分割；动作改变角度，不改变段长和宽。头、手、鞋或爪掌保持版本内比例。不得根据上一张图继续缩短或放大身体。

人类默认偏正半侧面，双眼可见，头身朝向协调；不要为固定角度扭曲姿势。近圆头、光滑单弧脸颊；额头留白大。睁眼的两颗实黑眼珠等径、等宽等高、边缘正圆，无高光；远侧眼也不因透视压扁或拉长，不用长条、椭圆、水滴或不规则黑点。保持小眼与疏朗间距；half_lid 只遮挡圆形眼珠上缘，不把露出部分拉成长豆形；closed_arc 仍为闭眼短弧，不强行替换成点眼。

人鼻为横向宽扁的半椭圆/C形，外侧鼻尖与下缘连续圆弧，开口朝脸内侧偏上。必须同时保留鼻根上方的脸轮廓断口：前额/前脸下降轮廓在鼻上缘之前结束，中间为明显、足够长的纯白通道，不是几乎接触的小缝，也不是仅凭C形内部留白冒充断口。朝左时断口在鼻根右上，朝右时在左上。鼻上缘仍保留短线，不能把整段上缘删掉；鼻下缘不向下开口。断口目标见 geometry.human.noseUpperGap，表示前脸线端到鼻上缘之间的净空白距离；不得有眉、眼线或连接线穿入。

嘴位于脸部较低、偏耳朵一侧的脸颊区域，与鼻呈斜向分离，不与眼珠刻意垂直对齐。鼻嘴间留充分白空间，嘴下方也留出下巴空白；鼻、嘴和下巴不相连。嘴长、弧度与张合由具体表情决定：平静可用舒展浅弧，开心可更长/更深或按事实张口，不满可用较长下弧；不能所有表情都固定成很短的钩或短划，也不为拉长而变成夸张咧嘴。禁止小圆钮鼻、猪鼻、鼻孔、鼻梁、连鼻笑线或酒窝。

脖子为细窄白色连接段，宽度见 geometry.human.neckWidth；头部大小、脖子长度及已认可肢体比例不变，领口随细脖子自然衔接，不画粗圆柱颈。远侧耳为简单空白圆弧，不加内耳线。正常与轻中度表情默认无眉，只在事实支持且明确指定的强烈夸张表情中临时加眉；闭眼弧和半睁眼睑不是眉毛，不误删。

描边统一为恒定粗细单线，开放线端均为圆头、转折圆润：鼻端、断口两端、嘴角、眼睑/临时眉、耳、领口与衣服线端同样适用。禁止笔压粗细变化、尖头收笔、楔形端点或重复描线。实黑发型的尖角属于填充轮廓，不等于开放线端，不把发型整体磨圆。旧参考的椭圆眼、短断口、粗脖子、短嘴与尖线端不覆盖这些规则。

猫狗采用夸张且极简的几何动物，不画写实解剖或毛茸茸吉祥物。四肢是短、极细的双线杆，宽度沿用该物种H下的legWidth；爪掌明显大于杆宽，像宽扁圆手套，最多两道简短趾分隔，不画尖爪、复杂肉垫或关节。头大、躯干紧凑，四足/坐/伏/仰睡按事件选择，仰睡允许四爪朝上，不强迫人类半侧面角度或人形站立。外轮廓只用连续光滑圆弧：零毛发线、零锯齿毛边、零颊毛、零胸毛、零额毛、零尾端毛簇，猫也不画胡须。狗用夸张的光滑长口鼻、末端小实黑鼻、简化垂耳辨认；猫用光滑近圆头、简单尖耳、小实黑鼻与光滑长尾辨认。除用户确认的身份色块外，不为“像动物”添加斑点或细节。

中性角色卡为两个等径正圆黑点眼、无眉。场景明确选用 neutral_dot、closed_arc（短闭眼弧）、half_lid（正圆黑眼珠与短眼睑）、wide_round（成对放大的正圆）、crossed（明确眩晕/撞击的叉形）。表情只改变眼、临时眉、嘴，不删除或替换鼻。每只猫在每种表情中都必须有一个小实黑鼻，位于双眼下方、嘴上方，与嘴之间留白；哈欠/O形嘴不能充当鼻，闭眼与不满也不能省略鼻。狗的口鼻末端实黑鼻同样一直保留。表情不改变眼位、头型和身份；不强迫所有场景中性，也不为多样性伪造情绪。eyebrows=raised/furrowed 仅在 intensity=strong 且场景明确需要夸张表情时可用；strong 也可以无眉，不能为加眉伪造强烈情绪。mild/medium 必须 none。临时眉放在眼上方且不得进入脸部断口。emotion 与 intensity 由 Agent 根据事实编写。嘴长、嘴形、手势和身体反应配合表情，最多两个外置情绪符号，不增添未授权文字。

黑白简笔墨线，少量人类头发、衣服、嘴洞纯黑块。无灰阶、光影、渐变、纹理、噪点、眼高光；动物完全不绘毛发，卡通毛边也不例外。角色卡/动作测试为白底清楚排列，完整头脚耳尾，不强制日记横线与日期。用户风格参考只提供造型语言，不复制角色身份或参考中的床、被子、文字与剧情。

diary 是一张3:4纯白纸海报，14–18条清晰但克制的等距浅青横线。顶部居中日期、下一行居中标题；标题约日期字号的1.25–1.35倍。固定字体与字号，不缩字挤版。每天只绘一张海报，容纳选定的1–5开放场景，不画漫画网格，不把全部原文塞进图。插画占约70–75%宽，右侧20–25%短备注栏；场景间至少一条横线空白。5场景优先降低背景复杂度并合并重复动作，不拆页、不缩小人物到不可辨。单场景适当放大，不补造事件。默认一名角色每场只出现一次。文字仅限明确可渲染字段，原文不是图上文字。
