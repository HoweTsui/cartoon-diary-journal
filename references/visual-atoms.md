# 视觉原子库

本文件把公开参考图中可复用的非专属结构拆成小原子。原子只帮助生图工具稳定复用，不允许复制原图人物、姓名、Logo 或整张表情表。`style-system.md` 与 `visual-gate.md` 的结构门禁优先。

## 组合顺序

1. 先锁黑白线稿、3:4 画幅、半侧面和统一线宽。
2. 再选每名角色自己的头型、发型/耳朵、衣物、配饰、身体和宠物物种原子。
3. 最后根据事件挑选一个受控表情原子。动作可以变，身份几何、鼻子、脸部断口、肢体管径和脚掌不能漂移。
4. 每个场景都写一份内部 scene inventory：主体、动作、关键道具/关系、必须保留事实和可灵活简化事实。

## 统一线条与头像

- 人物、动物、道具、家具、建筑、可见配饰（包括眼镜框、镜桥和镜腿）、地面动作线全部使用同一档约 5–6px 纯黑线；浅青横线纸是唯一例外。
- 背景只画理解动作所需的大结构，不能改用细工程线或灰线。
- 每名角色先生成独立 1:1 上半身头像，主体完整、水平居中、四周留白，再按相同顺序拼成总览图集。
- 图谱通过唯一 `avatarSrc` 直接读取头像；总览图集只作总览和旧数据回退，不作为新角色的唯一裁切来源。

## 人物头脸原子

### 头脸优先覆盖

头脸先照确认版 `character-lineup-demo.png` 与 `face-geometry-closeup.png` 的几何复用，再叠加身份和事件。头宽接近头高，不能拉长或放大；两枚同直径正圆眼略高且外侧眼留白；眼下是短、横向、上方开口的不填黑人鼻，鼻下是分离的低位小嘴；发际短弧后到鼻根保留空白断口。任何旧锚点、照片、发型夸张或表情都不能覆盖这组比例与位置。

### 轮廓与视角

- 头宽接近头高，可为略圆、梨形、软楔形或圆角梯形；不能拉成长椭圆或硬方盒。
- 每名角色明确朝左或右 25°–35° 偏正半侧面，鼻尖横向伸出，头脸与躯干同向；禁止正面、标准 90° 正侧面（直侧脸）或正面头接侧身。
- 前外侧只画一段从发际/刘海末端到外侧眼上方的短弧，随后到鼻根留下约 1.5 个眼点高度的空白断口。断口内不加眉线、额头线、鼻梁线或其他五官。
- 脸颊、下巴和后侧轮廓保持连续平滑；小耳位于侧后缘。耳朵只保留外轮廓，内部必须留白，不画内耳弧线、耳窝线、阴影线或装饰纹。

### 五官

- 中性基础眼为两枚无外轮廓的同直径正圆黑点，略高、外侧眼离头边留白；`canonical eye-dot diameter` 只锁定这一身份基准。
- 人物必须画出一个单独、清晰可见、上方开口、不填黑、横向宽于高的线描半椭圆鼻；鼻尖方向与面向一致，不能被嘴、轮廓、手或道具遮掉、合并或省略。禁止黑鼻、鼻孔、鼻梁、闭合 O 或向下 U/C 鼻。
- 嘴位于鼻下较低处，可用短横、上/下弧、黑嘴洞或少量露齿；不与鼻子重合。

## 身体与服装原子

- 躯干窄，最宽处不超过头宽约 55%；头高至少占站立全身约 30%。
- 上臂、前臂、大腿、小腿统一为同一目标粗细的超细双线白缝管，手臂和腿部保持一样细，首轮目标收细到头宽约 1/32；旧版 1/28 仅作兼容上限，外轮廓绝不超过头宽约 1/24，彼此误差不超过 10%。头部、手掌和鞋/脚保持确认版尺寸；躯干与头部以下身体段按上一版角色卡约 90% 处理，身体比例缩短约 10%，手掌只在末端略大。
- 短裤/长裤必须有裤腰、裆部分隔、两条裤腿和裤脚下沿；裤脚与细小腿之间留白分割，布料宽度不能延续到小腿。
- 动作只改变角度、姿势和手势，不加粗任何肢体；鞋为偏大的扁椭圆，手指用 3–4 个短弧即可。

## 动物原子

- 先组装大头、窄躯干、双耳、双眼、单一物种鼻、小嘴、细前后肢、略大爪掌和尾巴；自然四足、坐伏或小跑，不能人形站立。
- 动物不含爪掌的前后肢杆部与人物肢体使用同一 1/32 超细目标，旧版 1/28 仅为兼容上限，1/24 仅为绝对上限，彼此误差不超过 10%；爪掌可略大，每只脚只用 1–3 个圆钝趾口。
- 狗鼻是口鼻最前端的单个实心黑椭圆；猫鼻更小、位于双眼下方中央。动物不得使用人物开放鼻、鼻梁或鼻孔。
- 耳朵和尾巴按物种保留大形状，耳内保持空白无修饰线；长毛最多用 3–5 个圆钝轮廓起伏，不画逐撮毛刺、毛流、胡须、写实眼睛或高光。

## 受控表情原子（来自用户表情参考的抽象语义）

表情必须由“事件语义 + 嘴形/嘴洞 + 身体反应 + 最多两个外置符号”组成。眼睛允许变化，但只能从以下有限原子中选择；任何眼形变化都不能改头型、鼻子、脸部断口、眼位、身份轮廓或肢体。

| 原子 | 适用语义 | 具体限制 |
| --- | --- | --- |
| `neutral_dot` | 平静、观察、普通叙述 | 两枚同直径正圆黑点，身份基准 |
| `closed_arc` | 困倦、委屈、轻松 | 一或两条简短弧线；不能画睫毛或覆盖鼻子 |
| `half_lid` | 不满、怀疑、尴尬 | 短弧压在小圆点上；不画常驻眉毛 |
| `wide_round` | 突发、吃惊 | 只能是成对的圆形眼原子，不能变椭圆或写实眼 |
| `crossed` | 明确眩晕、撞击、失神 | 两个极简叉形；仅在文字事实支持时使用 |

嘴形、姿势和符号优先于眼睛变形：大笑可用黑嘴洞/露齿和身体弹起，生气可用下弧/握拳及头外短线，吃惊可用张嘴/后仰/放射线，困倦可用低位黑嘴洞与 `Z`，宠物互动只作为开心、喜爱或惊讶的场景修饰，不单独制造“宠物表情”。同页不要每格都用 `neutral_dot`。

禁止心形眼、钱币眼、太阳镜、白色高光、任意不规则眼、眼睛大小失控或表情让鼻子/嘴/另一只眼缺失。角色卡要记录所用 `eye_state`；出图逐项对照。

## 场景清单与验收

- `must_keep` 至少覆盖出场主体、核心动作、关键道具/数量和关系；`flexible` 只允许次要道具、背景和精确摆位在左/右/前/后/近/远语义内微调。
- 一页默认四个主叙事区；单事件放大为一个大场景并留干净空白，多事件聚合进四区，不新增漫画分格或第二页。
- 默认每名角色每个主场景只出现一次；只有原文明确序列、视频/镜像或同时不同动作时才重复，并继续复用同一角色卡。
- 生成后按清单检查：主体数量、动作、关系、表情眼原子、25°–35° 偏正半侧面（无正面、无真正 90° 正侧面）、断口、清晰鼻子、人兽鼻型、耳内空白、统一线宽、1/32 超细肢体、头/手/脚确认版尺寸、身体比例缩短约 10%、右侧备注、日期标题和文字。非关键偏差最多自动修两轮；关键事实、身份、几何或文字失败必须整页重生。
