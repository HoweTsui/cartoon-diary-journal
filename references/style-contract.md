# 固定画风合同

第一张附件 master-approved-v1.png 是唯一画风母版：每个人物、猫、狗沿用其五官结构、线条和比例。身份卡只提供发型、服装、配饰等身份特征；照片只提供事实，不继承照片的写实细节或旧卡的错误造型。不得重新设计成精致商业卡通。数值只从 geometry.json 读取。

- 人脸是母版的双眼可见侧向画法；两颗睁眼均为等径正圆实黑点，没有高光、椭圆或水滴眼。鼻子是横向宽扁开放 C 形，鼻根两端的横向位置应位于双眼中心垂直线之间；限制的是鼻根端点，不是向外突出的鼻尖。鼻根上方留断口，嘴在较低、偏耳侧，与鼻分离。动作不得改变这组相对位置。禁止正面小圆钮鼻、漏鼻或随场景重新布置五官。
- 人物身体沿用母版细双线白色四肢、窄颈和简化手鞋。猫狗沿用母版侧向圆润轮廓、细腿杆与较大爪掌；不画写实毛发或毛簇。狗保留较大的椭圆黑鼻，猫保留独立小黑鼻；颊纹只随身份，不强加。原文明示背影时可画背影，不能为强制侧脸改写事件。
- 表情仅改变已允许的嘴形、闭眼短弧或圆眼的受控状态；保留头型、眼位和鼻子。不可所有事件都统一笑脸，也不可把别人的情绪自动赋给动物。
- 恒定粗细黑色单线、圆头线端、平滑转折，身体和道具内部为不透明白色；只允许少量发型等身份黑块。无彩色、渐变、阴影、纹理、排线或摄影光感。浅青横线与悠哉文字由本地排版添加。
- 场景是自由轮廓的小插画：一个清楚的动作、必要道具、四周留白。仅保留说明地点所需的小片段，不填满房间、柜台、地板或透视背景。没有漫画框，也没有无边框却沿矩形齐边截断的背景。人物、耳、脚、尾和关键道具完整，环境线自然结束，不以直线切断图形。
- 每次日记生图只画一个场景；画布外部真实透明，四周有透明安全边，人物和道具内部白色保持。不得生成横向条带、三连画或整页五格。纸张、日期、标题、备注、横线全部留给本地合成。

母版和匹配的用户角色卡必须作为图片实际附给工具。新生成图仅是草稿；程序校验不等于画风已经正确。每次交付查看实际成图的五官、鼻根位置、侧向结构和自然边缘，不新增自动评分或自动循环重生。
