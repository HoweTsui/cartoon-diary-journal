# 日记页 QA 清单

## 当前 0.2.4 几何覆盖

首轮复核以头宽约 `1/32` 的超细肢体为准（旧版 `1/28` 仅作兼容上限，`1/24` 为绝对失败上限）；头部、手掌/爪掌和鞋/脚尺寸保持确认版，身体比例相对上一版缩短约 10%。人物和动物只允许 25°–35° 偏正半侧面，禁止正面和真正 90° 正侧面。

## P0 内容与版式

- [ ] `must_keep` 中的主体、数量、核心动作、关键道具和关系全部出现，未被风格化删除。
- [ ] 每张参考图和文字都完成 scene inventory；`flexible` 只影响次要道具、背景和相对摆位，不改变语义。
- [ ] `sourceImages` 均为仓库根目录下已存在的相对本地文件，并在四张固定参考之后按场景提供给 ImageGen；不存在、绝对或远程路径直接失败。
- [ ] 新海报严格 3:4；历史 9:16 仅在翻页书中 `contain` 完整显示，不裁切、不拉伸。
- [ ] 日期 `YYYY.MM.DD 周X` 在最上方居中，标题在下一行居中；日期/标题/备注/气泡字号跨页一致。
- [ ] 每场备注为 4–10 字，固定在该行插画右侧栏；相邻场景至少保留一条完整横线高度空白。
- [ ] 默认一张海报四个主叙事区；单事件使用一张大主场景，密集故事聚合进四区，不新增第二页或漫画格。
- [ ] 同一主场景默认每名角色只出现一次；只有原文明确序列、视频/镜像或不同同时动作时才重复。

## P0 人物与动物

### 头脸优先复核

- [ ] 头脸先与确认版图集比对：头宽/头高接近、未被拉长或放大；两枚同直径圆眼位置稳定；短横向开放鼻在眼下，低位嘴与鼻分离；短弧后的空白断口完整；不出现成人脸、长鼻、鼻嘴合并或夸张发型遮眼。

- [ ] 所有人物/动物清晰左或右 25°–35° 偏正半侧面，头脸与身体同向；无正面、标准 90° 正侧面、居中鼻子或正面头接侧身。
- [ ] 人物头型接近正圆但保留身份差异；前外侧短弧后至鼻根有约 1.5 个眼点高度空白断口，断口内无眉线/额头线/鼻梁线；耳朵只留外轮廓，内部无修饰线。
- [ ] 中性眼为等大的正圆黑点；表情眼仅使用 `neutral_dot`、`closed_arc`、`half_lid`、`wide_round`、`crossed` 中的受控原子，不能任意变形、高光或出现椭圆/杏仁眼。
- [ ] 人物只有一个单独且清晰可见的上方开口不填黑线描半椭圆鼻，不能丢失或被遮挡；动物只有一个物种正确且清晰可见的实心黑鼻；人兽鼻型不互换。
- [ ] 人物上臂、前臂、大腿、小腿与动物不含爪掌的肢体杆部为同一超细目标，首轮约头宽 1/32（旧版 1/28 仅作兼容上限），绝不超过头宽约 1/24，手臂和腿一样细，彼此误差不超过 10%；头部、手掌和鞋/脚尺寸不变，身体比例相对上一版缩短约 10%。
- [ ] 手掌/爪掌只在末端略大；短裤/长裤有裤腰、裆部分隔、裤脚下沿和白色分割；无粗臂、粗腿、粗动物肢体。
- [ ] 每个配角和宠物都逐一匹配自己的角色卡、头像/图集格位和锚点；不把主角结构套给其他角色。

## P0 线稿与表情

- [ ] 人物、动物、道具、可见配饰和背景环境均为同一档 5–6px 纯黑线；没有细工程线、灰线、灰阶、渐变、阴影、噪点或写实纹理。
- [ ] 若出现眼镜，镜框、镜桥、镜腿必须与人物主体使用同一档 5–6px 纯黑线；不得单独变粗、变细或改成发丝线。
- [ ] 表情由事件驱动，普通事件保持轻微变化，明确大笑/呲牙/生气/惊讶/困倦等才使用中强度；不让每格都呆板中性。
- [ ] 表情变化不改头型、鼻子、断口、眼位、发型、肢体长度、鞋/爪掌和动物物种；宠物互动不是独立的克隆角色。
- [ ] 文字由 ImageGen 用同一原创手写字体渲染；标题 ≤12 字、备注 4–10 字、气泡 ≤6 字，无额外文字或乱码。

## 修复门槛

- [ ] 非关键道具/摆位偏差最多自动修两轮。
- [ ] 身份、几何、主体数量、关键事实、文字或画幅失败时整页重生，不通过裁切、补线或文字解释交付。
- [ ] 两轮后仍有会改变含义的歧义，只亲切追问一个具体问题；没有歧义时直接完成。

- [ ] 视觉检查桌面双页、移动单页、日期标题、右侧备注、人物居中头像和 `character-graph.html?character=<角色ID>` 跳转。
