# QA Checklist

## P0 风格门禁

以下任意一项不满足，整页判失败并重生成，不接受“接近”或文字解释：

- 每个场景中的人物和动物均为约 25°-35° 偏正半侧面，鼻尖朝向明确，同时完整显示两只同直径、无轮廓、实心几何正圆豆豆眼；没有正面、近正面、单眼正侧面、椭圆眼、杏仁眼、空心眼或不规则点眼。
- 每个人物为约 25°-35° 偏正半侧面，头宽接近头高；两只同尺寸正圆黑眼略高，外侧眼不贴轮廓并保留白边。中性脸只允许双眼、单鼻和低位嘴。前外侧先有一小段贴着头形、从发际/刘海末端弧到外侧眼上方的短弧形轮廓线，再从该短弧末端到鼻根有约 1.5 个眼点高度的清晰空白断口。断口中没有任何线或额外五官标记，且前侧轮廓不是长直线。
- 人物鼻均为不填黑、非正圆、上方开口的线描半椭圆；动物鼻均为物种正确的单一实心黑鼻。人兽鼻型没有互换。
- 人物鼻横向宽于高且朝面向侧伸出，不是向下 U/C 形；站立人物头高至少约占全身高度 30%，短裤下小腿不超过约一个头高。
- 人物鼻子内部、上方、下方和旁边没有黑点鼻孔、第三个五官黑点或第二个鼻子。
- 人物躯干窄，上臂、前臂、大腿、小腿均为极细双线管，管径不超过头宽约 1/18；动物躯干简化，四肢杆部极细、爪掌略大。没有宽身板、粗臂、粗大腿、粗小腿或粗动物腿。
- 每个全身或坐姿人物都明确画出短裤/长裤的裤腰、裆部分隔、清晰裤脚下沿和两条独立裤腿；裤脚与极细小腿之间有白色分割，上衣没有直接连到腿，极细小腿从裤脚下方开始。
- 每个场景都有一条 4-10 字圆润卡通手写短总结；相邻场景所有图文外接范围之间至少有 1 条完整横线高度的空白带。
- 人物、动物、前景道具、家具、建筑和室内外背景全部使用同一档约 5-6px 纯黑线；只有横线纸为极浅青蓝。没有细工程线、灰线或背景专用细描边。

## 必过项

- 生图前已读取本次任务的 `character-graph.html`：每个出场角色均按 ID/准确姓名/唯一身份锚点命中，使用了对应图集格位；缺失或歧义角色已停止生图并完成补图入库，未用旧占位角色顶替。场景只使用图谱中已登记的关系。
- 每个场景均有逐角色卡（角色 ID、图集 `col`/`row`、全部 `anchors`）；每个可见人物或动物都匹配自己的卡和格位，主角没有被当作配角、路人或宠物的默认结构。
- 是严格 9:16 长竖版，场景沿页面由上至下连续展开，没有分格边框。
- 页面最顶部清楚显示 `YYYY.MM.DD 周X`，日期与真实周几一致。
- 日期下方有一句标题。
- 人物与物件只有纯黑和纸白；纸面只有 14-18 条等距的极浅青蓝横线。
- 人物使用身份图集的略圆但不几何化头型、两个略高、略拉开距离且尺寸/视觉粗细一致的正圆黑点眼（外侧眼不贴头部轮廓）、侧后小耳、鼻下偏低的小嘴；不画眉毛。前外侧的头部轮廓必须先从头顶/发际连续画到外侧眼上方，再从短弧末端到鼻根保留约 1.5 个眼点高度的清晰空白断口，断口不得被任何线补齐；其余脸颊、下巴和后侧头部轮廓必须连续平滑，不得出现折点、阶梯、硬直角或突然转折。每人只有一个不填黑的线描鼻，鼻型、鼻尖方向和表情匹配身份图集。鼻子本体应为略扁、非正圆的开放半椭圆，断口位于上方，端点停在双眼下方并只产生轻微遮挡；不得画完整闭合 O、实心黑鼻、长鼻梁、眉线或额头线。人脸双眼、单鼻、嘴不得缺失；动物必须保留物种需要的双耳、双眼、口鼻、四肢与尾巴，并使用符合物种的单一实心黑色动物鼻：狗在口鼻前端，猫更小且位于两眼下方中央；动物眼睛为无白色高光/反光的正圆实心黑点；不得出现人物开放半椭圆鼻、鼻梁线、鼻孔或 C 形/额外突出的鼻形轮廓。使用约 5–6px（1024px 宽画布）的统一黑线、极细双线管状上臂/前臂/大腿/小腿、略放大的简洁掌部和 3–4 个短指弧、偏大扁鞋；肢体管径不超过头宽约 1/18，躯干最宽处不超过头宽约 55%。
- 纯黑块只用于嘴、头发、上衣或鞋；线条稚拙但清晰，不是圆润厚描边。
- 没有纸纤维、颗粒、噪点、斑点或复古做旧。
- 没有写实光影、体积、皮肤或食物渲染。
- 每个固定人物匹配图集的头型、双眼位置与间距、鼻型与鼻向、鼻子自身开口、眼嘴、发丝、配饰、黑块位置、服装结构、双线腿和鞋形。
- 本次新增人物若来自用户上传图片，照片只贡献身份线索；其线重、五官简化方式、鼻子自身开口、四肢结构、头身比和黑白块面必须与现有人物图集逐项一致，不能出现半写实或另一套卡通风格。
- 宠物必须是平面简化剪影；只保留头、躯干、口鼻、耳、四肢/脚掌和尾巴等大结构，不使用彩色毛色块；长毛品种最多 3–5 个大圆钝轮廓起伏。不得出现真实毛发束、逐撮毛刺、密集围脖、胡须细节、任何白色眼睛高光/反光点、毛色渐变或写实肌肉结构。
- 动物的窄躯干、极细前后肢、略大脚掌、尾巴和物种正确的单一黑色动物鼻应保持简洁，并与该动物的身份锚点一致；不得把某只动物的比例、口鼻或坐姿套给另一物种。狗头须明显大于躯干、双正圆黑点眼距偏宽、鼻子为口鼻前端的单一黑椭圆，脚掌为短圆弧并且每脚仅 1–3 个简化趾口；不得出现写实犬类解剖、粗动物腿、精细脚趾或关节。猫鼻不得变成狗鼻大小或落在口鼻尖端。不得出现人物鼻子、鼻梁/鼻孔、写实四肢或三角湿鼻。
- 表情变化只改变低位嘴洞/嘴角/简化露齿和不超过两个外置情绪符号；双眼始终是完整、同尺寸的正圆黑点，不得闭合、变形、换成符号或被遮住。中性脸不画眉毛，愤怒或疑惑仅允许头外 1–2 条临时短情绪线。头型、鼻子位置、发型/耳朵、手指、四肢长度、鞋/脚掌和头身比必须与中性图一致，双眼、单鼻、嘴不得缺失。
- 每个开放场景只表达一个动作并配一条 4-10 字短总结；总场景数为 3-6；相邻场景之间至少有 1 条横线高度的完整空白带。可选对话/想法气泡不超过 3 个、每个 1-6 字，且不能代替短总结。
- 中文短、少、基本可读。
- 没有复制私人信息或已出版作品的具体元素。

## 失败即重生成

- 日期缺失、在中部、格式错误或周几错误。
- 任一人物或动物变成正面/近正面、单眼正侧面或与图集视角不一致；人物缺少短弧末端到鼻根的清晰空白断口，或外侧眼贴轮廓。
- 人物鼻变成向下 U/C 形，或人头小、躯干/腿被拉成长成人比例。
- 人物出现实心黑鼻、动物鼻、正圆鼻、完整闭合鼻、方盒鼻、鼻向与面向冲突；动物出现人物开放半椭圆鼻、鼻梁或鼻孔。
- 人物或动物出现粗手臂、粗大腿、粗小腿、粗动物四肢、宽身板、块状掌、常规可爱儿童插画、漫画美型脸或写实人物；或硬直角头、脸部折点/阶梯/突然转折、五官或宠物耳朵缺失。
- 新上传人物与图集在线重、五官语法、四肢粗细、头身比或黑白块面上出现明显漂移。
- 任一配角、路人或宠物未匹配自己的场景角色卡/图集格位，或直接复用主角头脸、衣物、肢体或动物结构。
- 表情导致五官缺失、常驻眉毛、身份轮廓改变，或宠物出现人物鼻子、鼻梁/鼻孔、写实鼻口、逐撮毛刺或真实毛发。
- 肢体恢复正常粗细、鞋变小，或头身比不再故意笨拙。
- 同一人物在不同格换头型、眼镜、发夹、衣服或宠物耳形。
- 出现渐变、柔光、厚重阴影、灰阶体积或彩色厚涂。
- 背景细节超过主体，或页面出现漫画分格、像 PPT、照片拼贴。
- 人物、动物、道具与背景环境线宽不一致，或背景出现细工程线、灰线、轻描边。
- 任一场景缺少短总结，气泡替代短总结，或相邻场景图文之间没有完整空白带。
- 参考图中的姓名、日期、地点、品牌、商品或脸被复用。

## 单点修复

- 太普通：锁住图集头型、双点眼间距、单鼻结构与鼻向；改成中粗线、细长双线小腿，放大鞋，减少发丝，并加入符合其表情的纯黑嘴洞或衣鞋块面；不得为求风格而统一拉长鼻子，圆鼻必须在自身轮廓留开口。
- 太精致：删除灰阶和阴影，改成纯黑细墨线。
- 太脏：要求 smooth clean paper、zero grain、zero speckles。
- 人物漂移：重新附身份图集并逐人重复锚点。
- 文字错一处：局部编辑；错三处以上：减少文字并重生成。
- 日期错：只编辑顶部日期，不改画面。

## HTML 图谱

- 页面标题只写“人物关系图”，没有日期、周几或时间线信息。
- `graph-data.status` 是 `actual`，人物与关系逐字段等于本次任务数据；没有遗留占位人物或旧关系描述。
- 实际人物头像全部裁切到数据指定的正确格位。
- 浏览态只显示纯文本；没有人物输入框、关系选择框、删除按钮或新增人物按钮。
- 默认和选中人物状态的右侧按钮均显示“编辑”；点击“编辑”后才显示人物字段、新增人物和新增关系表单。
- 编辑态双击连线名称会显示内联输入框；Enter 保存新名称，Escape 保留原名称。
- 拖拽节点时连线实时跟随。
- 把人物节点拖近其他节点会平滑推开邻近节点；动画结束后人物圆形和姓名标签均不重叠。
- 点击“编排”会在 300-500ms 内完成位置过渡：无环图为层次布局，有环/稠密图为力导向布局；撤销、重做可恢复前后位置，手动拖拽也会进入位置历史。
- 50 个以上节点的力导向计算分帧执行，交互和绘制不应长时间阻塞。
- 从节点 `+` 控制点拖到另一节点会吸附并新增连线。
- 把已有连线端点向节点外拖出会删除该关系。
- 空白拖动画布有效；滚轮缩放以指针为中心。
- 搜索、关系筛选、复位和人物卡有效。
- 新增人物后可拖拽并显示首字占位头像；保存详情后画布和人物卡同步更新。
- 删除人物会同步删除其关系；新增和删除关系会立刻更新连线与计数。
- 刷新页面后节点位置、人物信息和关系仍保留；更换任务数据后不会加载旧任务缓存。
- 桌面与窄屏均无主要内容裁切。
