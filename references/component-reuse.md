# 组件复用试用版

默认母版已接入正式生成入口。此页记录可直接复用的组件与动作；只有属于本次用户角色的已确认素材才可直接放进真实日记，示例角色只供画法参考。

## 固定单元

母版为 style-lock-v1/master-approved-v1.png，组件定义在 assets/style-reference/style-lock-v1/components-v1.json。源图用 SHA-256 校验；缺失或不一致即停止，不使用旧参考包或纯文字生成兜底。

当前最小可用于场景的单元是整个人物站姿、猫坐姿、狗坐姿。五官与头部不拆开，也不单独移动眼睛、鼻子；另有三个面部参考视窗，仅供查看，不冒充已经实现头身拼接。组件只支持等比缩放和平移，不镜像、不旋转、不拉伸、不重画，保留原图的双眼可见侧向视角。原图保留，不做全白透明化或像素硬边处理。

这三个角色只是风格示例，不代表用户身份。原母版获认可不等于新的组件定义、组合效果或新人物身份自动获认可。

2026-09-21 用户已确认 component-trial-v2 的五官与组合效果，components-v1.json 已记录该范围的批准。此批准不延伸至后续新增动作。

## 使用

运行 `python3 scripts/build_component_trial.py --output-dir task-output/component-trial-v1`，产出独立组件 PNG、含日期标题备注的示例海报 PNG、总览 HTML 和可追溯复用记录。只使用 Pillow 和随 Skill 附带的悠哉字体，不调用生图工具。

示例为虚构的静态陪伴场景，不入真实日记，不把站姿称为走路或把坐姿称为玩耍。已有动作不匹配用户原文时，不能修改事件迎合素材。

## 首批新增动作（已确认）

2026-09-21，用户已确认人物走路、坐着看书；猫走路、趴卧；狗走路、低头闻闻，共六个独立透明 PNG。最新索引是 `assets/style-reference/style-lock-v1/action-library-v2.json`，批准记录见 `assets/style-reference/style-lock-v1/actions-v1/approval.json`。对应脚本 `scripts/build_action_trial.py`；运行 `python3 scripts/build_action_trial.py --output-dir task-output/action-library-v2-approved` 可只复用这些已确认素材产出示例。不要对已有库重复运行 `--package`。

`load_action(action_id, preview=False)` 会校验母版、身份参考和动作图片的哈希；正式模式同时要求动作库和指定动作都由用户批准。明确预览才传 `preview=True`。使用动作 ID 精确选择：匹配的已确认动作优先直接复用，缺失时报错，不能偷偷换其他动作、重新生成已有姿势或改变用户事件。旧 `action-library-v1.json` 是本轮中间稿，新任务只使用 v2。

新动作通过内置 ImageGen 编辑生成，最初实际附上母版、已确认全身、面部特写；局部修正附编辑目标与对应已确认角色参考。提示词和输入记录保存在 `actions-v1/generation-requests.json`、`correction-prompts.json`、`cat-leg-correction.json`。不会声称这些新脸是旧脸的逐像素复制；现在复用的是已经确认的动作素材本身。

保留生成 alpha，不把白色内部一并抠掉。示例海报按组合后实际可见范围计算文字中心，再用悠哉字体合成，不能用透明画布中心代替动作中心。每个角色的左右朝向由素材确定，不用镜像凑朝向。

## 未覆盖能力

尚未提供通用拿物、任意身体姿势替换、头身接点、左向版本或新表情。新增这些能力时以原母版和当前角色卡为输入，只补缺少的动作/表情，保留现有资产；必要时使用生图编辑，再确认新组件。未经实现与验证，不能声称局部编辑会像素级保留脸部。

需要生成新组件时，实际附上母版、当前角色卡和匹配动作参考，不仅提供路径文字；工具无法附图则报告停止。当前脚本只能验证本地素材及复用来源，不能证明外部工具收到附件。没有自动风格评分、择优或循环重生。

本次稳定性保证仅限于直接复用同一素材：原始五官相对几何不变，缩放会重采样像素，不承诺所有缩放下像素逐点相同，也不保证新生成动作自动一致。当前六个动作的 `identityScope` 是 `fictional-demo-only`，不能直接冒充真实用户角色；真实人物或宠物须先建立并经用户确认自己的同类动作库。
